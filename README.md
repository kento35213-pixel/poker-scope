# POKER SCOPE v2

日本語のノーリミットホールデム学習アプリ。キャッシュクイズ、MTTクイズ、スポット解析、エクイティ計算機、学習記録を備えるWebアプリです。外部CDNや有料APIに依存しない静的HTML/JavaScriptです。

## 公開するには

GitHubとCloudflareへの公開手順は [DEPLOY.md](DEPLOY.md) を参照してください。ZIPの中身をリポジトリ直下に配置します。Cloudflare Workersの静的アセット配信を使い、`wrangler.jsonc` の設定で `dist/` を公開します。

```sh
npm ci
npm run dev
# 本番公開
npm run deploy
```

## v2の問題セット

GTO Wizardの公開教材17件を調べ、43テーマの自作問題に再構成しました。参照先と調査結果はアプリ内の「参考資料と問題構成」および RESEARCH.md に記載しています。

- 途中の行動を固定確率で選ぶ旧シミュレーターと、出題までコールを強制する処理を削除。
- テーマごとに整合する合法な履歴を先に構築。オープン、BBディフェンス、3/4ベット、スクイーズ、CB、チェックレイズ、プローブ、ターンドンク、ショート、リバー、ICMを区別。
- 通常のキャッシュでフィールドのオープンリンプや、複数人の連続コールドコールを標準履歴に含めない。
- MTTのSBや短いBTNのリンプ、低い連結ボード等でのリードは例外テーマとして残す。
- 標準練習の例外テーマの重みは主要テーマの0.06倍。「テーマ均等」「例外集中」やテーマごとの指定も可能。この重みは教育用であり、実戦のGTO行動頻度ではない。
- テーマ、対応スタック、レンジ内ハンド、同型のスート等をランダム抽選。資料で扱っていない条件に自動的な正解や数値を捏造せず、未収録の組合せを明示。
- 回答前に意図する答えを見出しで示さず、アクションを一手ずつ再生してから出題。

## 採点を区別

### 公開教材の原則を問う問題

記事を丸写しした問題集ではなく、説明された原則と局面構造を使う自作問題です。未公表のコンボ別GTO頻度やEVは表示しません。「教材の主眼」と「許容する別解」を両方正答とし、教材スコアで評価します。このスコアはGTOのEV損失ではありません。

キャッシュ・MTT、位置、スタック、ツリーのすべての条件が元の公開例と一致するフルソルバー解を複製したものではありません。原則を別の条件へ適用した問題も含みます。各問に参照記事と、この範囲の説明を表示します。

### 固定レンジの数理ドリル

リバーは、問題文で示す価値とブラフのレンジを固定し、既知カードを除いた全コンボを判定して、コール／フォールドの条件付きEVを計算します。レーキ0・ポットベット・ブラフ1/3の無差別条件では両方を正答にします。

MTTのバブル・ファイナルは全員のスタック、賞金、相手のジャムレンジを問題文に表示。勝ち・負け・同点・フォールド後のスタックをICMに変換します。ハンドの勝敗は30,000回の試行で求め、誤差を表示します。試行誤差内の選択はミス判定から除きます。相手のレンジを最適化したトーナメントGTO解ではありません。

### ソルバー解の取り込み

利用者が提供したJSONの戦略頻度・EVを参照します。実際のソルバー解との厳密な照合はこちらの問題を使用してください。解の精度をアプリが独自に保証するものではありません。生のエクスポートには専用形式への変換が必要です。ひな形と仕様は画面内から確認できます。

### 自由入力のスポット解析

既存の参考計算機能を継続。ヘッズアップのキャッシュ／MTT序盤は各レンジ最大18コンボ・14,000反復の1ストリート簡略CFR。将来はチェックダウン、再レイズ等を省略し、エクスプロイタビリティ未測定です。多人数やICMの自由解析には応答仮定・決着の簡略化があります。フルゲームのGTOソルバーではありません。

## 記録・ツール

- 学習記録はIndexedDBに端末内保存。使用不可時はlocalStorageへフォールバック。
- 直近20 / 100問、7 / 30日、全期間、期間指定。モードと教材v2／以前の近似モデル／取込解で絞り込み。
- ストリート、ポジション、スタック、テーマ別の成績、推移、回答一覧、ミスの復習。
- 旧成績を新しい教材の成績から区別。旧HU履歴の再生互換を保ち、新しいHUではBBがポストフロップに先に動く。
- JSONバックアップ・復元と重複防止、CSV出力。端末間同期はしない。
- エクイティ計算機は2〜6人、ボード0〜5枚。120,000通り以下は全列挙、それ以外はモンテカルロ。単独勝率・同点率・ポット取り分と誤差を表示。

## 検証

```
node --check dist/engine.js
node --check dist/study.js
node --check dist/app.js
node --check dist/worker.js
node --test tests/engine.test.cjs tests/study.test.cjs tests/app.test.cjs
node tests/sample-curriculum.cjs
```

カードと役判定、全列挙、同点配分、ICM、レイズ権、超過額、履歴の保存則、テーマ全件の合法性、出典、抽選の偏り、数理EV、HUの手番、画面切替・保存・復元・回答の二重登録防止・答えの事前漏えい等を確認します。標準練習の各10,000問の監査結果を tests/sampling-v2.json に保存しています。これはGTOの行動頻度の推定ではありません。

ブラウザではプレビュー上で出題、アクション再生、回答、解説と参照先を確認。実機のモバイルSafariは未検証です。

## ファイル

- dist/index.html / style.css / icon.svg：画面とスタイル
- dist/app.js：4モード、記録、保存、各入力
- dist/engine.js：カード、役判定、合法アクション、ICM、参考解析、インポート検証
- dist/study.js：公開資料、43テーマ、整合する履歴、教材判定、固定レンジ数理EV
- dist/worker.js：画面を止めないバックグラウンド計算
- tests/：Node標準ライブラリのみの検証・抽選監査
- RESEARCH.md：調査と反映範囲
- wrangler.jsonc：Cloudflare Workersの配信設定
- package.json / package-lock.json：開発・検証・デプロイコマンドと依存関係
- DEPLOY.md：GitHub・Cloudflareへの公開手順
